# BloodLink – Blood Donor Finder

BloodLink is a secure, responsive, and real-time blood donation platform designed to connect patients, blood donors, blood banks, and hospitals during critical medical emergencies. The application reduces the time required to locate blood by offering instant notifications, nearby blood bank search via Google Maps, and real-time inventory management.

## 🚀 Key Features

*   **Real-time Alerts & Notifications:** Instantly notify nearby donors and blood banks when emergency requests are made.
*   **Google Maps Integration:** View nearby blood banks, user locations, and get directions.
*   **Real-time Inventory Management:** Allows blood banks/admins to update and manage blood group stocks.
*   **Role-Based Access Control:** Distinct workflows for general Users and Admins.
*   **Secure Authentication:** Secure JWT-based registration and login with encrypted passwords.

## 🛠️ Tech Stack

*   **Frontend:** React, Tailwind CSS, Framer Motion, Axios, React Router
*   **Backend:** Node.js, Express.js
*   **Database:** MongoDB Atlas, Mongoose
*   **Authentication:** JWT, bcrypt
*   **Notifications:** Firebase Cloud Messaging, Socket.IO
*   **Maps API:** Google Maps API
